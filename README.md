# Ассистент встреч (Android, офлайн)

Записывает встречу по кнопке в фоне, расшифровывает речь и делает резюме с решениями и задачами.
Всё работает на телефоне без интернета: запись, расшифровка (Whisper через whisper.cpp) и резюме
(локальная модель Qwen через llama.cpp). Интернет нужен только один раз, чтобы скачать модели,
либо модели можно скопировать с компьютера.

## Как поставить

1. Откройте вкладку **Actions** в этом репозитории, выберите последний запуск «Build Android APK»
   и скачайте артефакт `meeting-assistant-apk` (zip с APK внутри).
2. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).
3. В приложении нажмите **Модели** и скачайте по Wi‑Fi:
   - Whisper Small (~190 МБ) для расшифровки;
   - Qwen3 4B Instruct (~2,5 ГБ) для резюме, или Qwen2.5 1.5B (~1,1 ГБ) для телефонов с 4 ГБ ОЗУ.

### Модели без интернета на телефоне

Скачайте файлы на компьютере, скопируйте в память телефона и в приложении нажмите «Из файла»:

| Модель | Файл |

## Как пользоваться

- Большая красная кнопка начинает запись. Экран можно заблокировать: запись идёт в фоновой службе,
  в шторке висит уведомление с кнопкой «Остановить».
- После остановки сразу начинается обработка: сначала расшифровка, потом резюме. Пока идёт
  обработка, приложение лучше держать открытым (экран не гаснет сам).
- В карточке встречи есть вкладки «Резюме» и «Расшифровка», кнопка «Поделиться» и
  «Пересоставить резюме».

Ориентир по скорости на современном телефоне: расшифровка моделью Small занимает примерно
от трети до половины длительности записи, резюме часовой встречи моделью 4B ещё 5–15 минут.

## Устройство

- `modules/meeting-recorder` — свой нативный модуль (Kotlin): foreground‑служба с микрофоном,
  пишет WAV 16 кГц моно, который whisper.cpp читает напрямую.
- `src/ai.ts` — расшифровка (`whisper.rn`) и резюме (`llama.rn`); длинные встречи
  резюмируются по частям, потом части сводятся в итог.
- `src/models.ts` — список моделей, загрузка и импорт из файла.
- `App.tsx` — экраны: запись и список, встреча, модели.

## Сборка локально

Нужны Node 22, JDK 17 и Android SDK.

```sh
npm ci
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
```
